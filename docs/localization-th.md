# สถานะและแผนงานภาษาไทย — WordCraft TH

สถานะปัจจุบัน: เอกสารและ upstream manifest เท่านั้น ยังไม่มีซอร์สแอป คำแปลที่พร้อมแจก หรือไฟล์ติดตั้ง TH ใน repository นี้

## ก่อนเผยแพร่รุ่นไทย

- นำซอร์สต้นทางเข้ามาโดยบันทึก revision และคงเครดิต/ใบอนุญาตเดิม
- ตรวจระบบ i18n และรายการข้อความของ revision ที่เลือก
- แปลและทบทวนศัพท์ ตรวจ placeholders ตัวเลขและปุ่มลัด
- ตรวจฟอนต์และการแสดงผลภาษาไทยด้วยหน้าจอแอปจริง
- ตรวจคำแปลที่ขาดและทดสอบการเปิด/บันทึก/ส่งออกตามขอบเขตรุ่น
- สร้างและตรวจแพ็กเกจ Mac/Windows พร้อม SHA-256 และข้อจำกัดที่พบจริง
- เผยแพร่ภาพหน้าจอ ผลทดสอบ และ Version Log ของรุ่นไทยแยกจากต้นฉบับ

ยังไม่กำหนดวันเสร็จและไม่ใส่ตัวเลขความครอบคลุมที่ยังไม่ได้ตรวจจริง หากใช้ AI ช่วยร่างคำแปล จะระบุวิธีและขอบเขตการทบทวนไว้เมื่อมีการเผยแพร่
