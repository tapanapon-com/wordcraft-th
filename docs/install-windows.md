# ติดตั้ง WordCraft บน Windows / Windows installation

**รุ่นไทยยังไม่เผยแพร่** ลิงก์ต่อไปนี้เป็นต้นฉบับ [v0.16.0](https://github.com/storytold/wordcraft/releases/tag/v0.16.0)

## แบบ MSI

บันทึกงานและปิดแอปเดิม เปิด MSI แล้วทำตามหน้าจอติดตั้ง จดโฟลเดอร์ติดตั้งไว้ จากนั้นเปิดแอปจาก Start Menu

## แบบ Portable

ใช้ Extract All แตก ZIP ลงโฟลเดอร์ที่เขียนไฟล์ได้ แล้วเปิด `wordcraft.exe` จากโฟลเดอร์ที่แตกเสร็จ เก็บไฟล์ที่มาพร้อมกันไว้ครบ ไม่เปิดโปรแกรมจากภายใน ZIP

เลือก x64, ARM64 หรือ x86 ให้ตรงกับเครื่องและการรองรับของต้นทาง ตรวจ hash กับไฟล์ชนิดเดียวกันใน Release เดียวกัน รายละเอียดการเซ็นและข้อกำหนดระบบให้ยึดผู้เผยแพร่ต้นฉบับ

## English

These are upstream installers, not Thai-edition packages. Choose the matching architecture. Run the MSI to install, or extract the complete portable ZIP before launching `wordcraft.exe`. Keep companion files together and verify the matching SHA-256 from the same release.
